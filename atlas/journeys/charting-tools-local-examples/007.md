## What I found

This file is a goldmine for my task. Two things stand out:

**1. `scaffold_mind()` (line 412) is the exact pattern I need.**

It takes a name, a directory, and a `TemplateRenderer`. It creates directory structure, writes template files into it, and returns a domain object. The function:
- Creates directories with `mkdir(parents=True, exist_ok=True)`
- Uses `templates.write()` for templated files
- Has a `skip_existing` flag for idempotent scaffolding
- Takes explicit parameters (not `ctx`) — reusable from anywhere

My "ensure example journey exists" logic is a smaller version of this same pattern: check if a directory exists, if not, populate it from templates/assets, return the result.

**2. `ensure_structure()` on the `Mind` class (line 98) is the validation/repair pattern.**

It checks if expected directories and files exist, optionally creates them, and returns a list of issues. This is the "check and fix" pattern — exactly what I'd need for "does the example folder exist and have content?"

**Key difference from what I was thinking:** `scaffold_mind()` takes a `TemplateRenderer` to write `.j2` templates. But for examples, I'm copying static files (real markdown files from `__assets__/chart/example-journey/`), not rendering templates. So the pattern is similar but the mechanism is simpler — `shutil.copytree` or iterating and copying files.

**The helper pattern confirmed:**
- Standalone functions with explicit `Path` parameters
- No `ctx` dependency — commands provide the paths
- Lives in `haiv/helpers/`
- Returns domain objects or data, not strings for display
- `TemplateRenderer` passed in when needed, not imported

**Design forming:** I should create `helpers/atlas.py` (or maybe `helpers/charting.py`). It would have a function like:

```python
def ensure_example_journey(
    examples_dir: Path,
    bundled_assets_dir: Path,
) -> list[Path]:
    """Ensure the project-local example journey folder has content.

    If examples_dir is empty or missing, copies from bundled_assets_dir.
    Returns list of example files.
    """
```

Both `_index_.py` and `explore.py` can call this. The command decides what to do with the result (display it, pass it to a template, etc.).
